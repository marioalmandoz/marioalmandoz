# Mario Almandoz

Product-minded software engineer focused on agentic AI and full-stack TypeScript. I like turning real problems into products people actually use, and I build them from architecture to launch.

## What I'm building

- **[ShopiBai](https://shopibai.com)**: production SaaS that turns every Shopify sale into a digitally signed TicketBAI invoice and submits it to the tax authority in real time. As the sole engineer, I built the integrations with 4 tax authority systems: XAdES-EPES signatures, BullMQ/Redis job queues with automatic retries and PostgreSQL locking for invoice-chain integrity. 1,200+ invoices processed.
- **[CestaChef](https://www.cestachef.es)**: meal-planning app for iOS and Android with real supermarket prices from 4 countries and 90,000+ downloads. As co-founder and CTO, I lead engineering across the React + Capacitor app on Supabase, an LLM agent with human-in-the-loop review, and a codebase backed by 900+ automated tests and CI.
- **Maxworld** (New York): AI Product Engineer. I own the company's web products end to end, including LoveSigns, a bilingual platform where the Claude API generates personalized reports, and the automation of internal processes with AI.

Most of this code lives in private repositories.

## How I work

AI-native development with Claude Code. I start with a plan, review and correct it, and only then build, with tests and CI as quality gates. When I put AI into a product, it starts with a human in the loop and earns autonomy as it proves reliable.
